# Nouveautés

Chaque version : ce qui change pour toi, en clair. Rien à faire sauf mention « À faire ».

## v0.1.3
- **Nouveau** : Artemis te prévient sur Telegram quand une nouvelle version existe (une fois par version, jamais de spam)
- **Nouveau** : `./update.sh` met tout à jour d'une commande
- **À faire** (une seule fois) : `git pull` puis `./install.sh`. Ensuite, `./update.sh` suffira

## v0.1.2
- **Nouveau** : les rappels. Dis « rappelle-moi lundi 18h30 de… », tu reçois le message sur Telegram à l'heure dite
- **Nouveau** : envoie un lien TikTok de cuisine, Artemis l'ajoute à tes recettes
- **À faire** : `./install.sh` pour activer les rappels

## v0.1.1
- **Nouveau** : `./setup.sh` installe tout en te posant 3-4 questions (plus d'appairage à la main)
- **Nouveau** : Discord en option
