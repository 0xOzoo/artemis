# Menus et courses

## Méthode (pour le recalcul)
1. Lire [[cuisine/profil-et-stock]] (goûts, interdits, rythme, stock, réservé, budget, matériel).
2. Prendre les repas du menu ci-dessous, retrouver chaque recette dans [[cuisine/recettes]], sommer les ingrédients.
3. Soustraire le stock ; arrondir au conditionnement du commerce ; ne jamais ajouter un produit refusé ou interdit.
4. Si le budget est connu, additionner les `prix` ; sinon le demander.
5. Mettre à jour cette note et le stock après les courses.
